# Power BI: запросы и меры

Файлы для чтения кода отчёта `report/kp_expertise.pbix` без открытия Power BI. Данные учебные.

| Файл | Что внутри |
|---|---|
| `queries.pq` | тексты запросов Power Query (приведение КП, сравнение со справочником, ведомость × подрядчики) |
| `measures.dax` | тексты мер DAX (суммы по ценам КП и по справочным ценам, доля, счётчики для карточек) |

## Запросы

| Запрос | Назначение |
|---|---|
| `pFolder` | параметр: путь к папке `data/source/` |
| `tMap` | соответствие названий позиций в КП и кодов ведомости |
| `tRef` | справочник цен без НДС на 31.03.2026 |
| `KP_A`, `KP_B`, `KP_V1`, `KP_V2`, `KP_G` | чтение и приведение КП каждого подрядчика (НДС, тысячи рублей, состав цены) |
| `KP_Clean` | все КП в одной таблице, индексация цен, сравнение со справочником, флаги |
| `tContr` | список подрядчиков |
| `tVOR` | ведомость объёмов × подрядчики, статус позиции, итоговая сумма |

## Как использовать

1. В Power BI: **Home → Transform data**.
2. Создайте параметр `pFolder` (**Manage parameters → New parameter**, тип Text) и укажите путь к `data/source/` со слэшем в конце.
3. Для каждого запроса: **Home → Advanced Editor**, вставьте код из `queries.pq` с тем же названием.
4. Меры из `measures.dax` добавляются через **New measure**.
